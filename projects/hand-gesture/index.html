✋ Hand Gesture Controller

Sistem kontrol komputer menggunakan gesture tangan yang dikembangkan dengan Python dan MediaPipe. Project ini mengeksplorasi computer vision, gesture recognition, dan interactive control.

🖐️ Hand Detection

Mendeteksi posisi tangan menggunakan teknologi computer vision.

🎯 Gesture Recognition

Mengenali berbagai gesture tangan untuk menjalankan perintah tertentu.

💻 Computer Control

Gesture dapat digunakan sebagai metode interaksi dengan komputer.

🐍 Python

Project dikembangkan menggunakan bahasa pemrograman Python.

📷 MediaPipe

Menggunakan MediaPipe untuk membantu proses hand tracking dan gesture detection.

🤖 Interactive Visual

Project dapat dikembangkan menjadi sistem visual interaktif seperti virtual controller.

🚧 Development

Project masih dalam tahap pengembangan dan akan terus ditambahkan fitur interaktif.
