🤖 Jarvis AI

Personal AI assistant berbasis Python yang dikembangkan untuk membantu menjalankan perintah suara, membuka aplikasi, melakukan otomatisasi teks, dan berinteraksi dengan komputer.

🎙️ Voice Command

Menerima perintah suara untuk menjalankan berbagai fungsi pada komputer.

🧠 AI Assistant

Sistem asisten pribadi yang dapat membantu menjalankan tugas berdasarkan perintah pengguna.

💻 App Control

Mengontrol dan membuka aplikasi komputer melalui perintah.

⌨️ Text Automation

Membantu mengetik dan melakukan tugas otomatisasi sederhana.

🐍 Python Based

Dikembangkan menggunakan Python dan berbagai library pendukung.

⚙️ Hybrid Assistant

Dirancang sebagai personal assistant yang menggabungkan voice command dan AI.

🚧 Development

Project masih dalam tahap pengembangan dan akan terus ditambahkan fitur baru.
